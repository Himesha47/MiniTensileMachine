# MiniTensileMachine
Arduino + HX711 +NEMA17 Stepper motor with A4988 driver
Miniature Tensile Testing Machine
This project is about designing and building a low-cost miniature tensile testing machine using:
    Arduino Uno
    A4988 Stepper Driver
    HX711 Load Cell
    Python GUI
Functions: Force measurement
           Displacement measurement
           Real-time plotting
           Data logging
